# Calendar 366 for Claude

A Claude Desktop extension that enables Claude to read and manage events and tasks in [Calendar 366](https://calendar366.com).

## Getting Started

1. Download the latest `.mcpb` from the Releases section of this repository.
2. Open the downloaded file. Claude Desktop will install it automatically.
3. Ensure Calendar 366 is running on the same Mac.

## Capabilities

* List all calendars, task lists, and configured calendar sets
* Retrieve events and tasks for a given date range or calendar set
* View full details of a single item, including notes, alerts, recurrence, and attendees
* Create new events and tasks, including all-day and multi-day items
* Update, move, duplicate, or delete existing items
* Provide the current local date and timezone for accurate scheduling

## Requirements

* macOS
* Claude Desktop `>= 0.10.0`
* Calendar 366 v3.0.6 installed on the same Mac

## Data Handling

The extension communicates with Calendar 366 entirely on-device. Calendar data never leaves your Mac.

## About This Repository

This repository hosts the signed, distributable `.mcpb` bundle and the changelog. The source code of the underlying application and bridge is maintained privately.
